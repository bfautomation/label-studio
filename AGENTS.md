# Agent instructions

This repository is a **public** fork: everything you write into it or post to it can be read by anyone and stays in
history. Read and follow [`FORK_PRIVACY.md`](FORK_PRIVACY.md) before you write any of these:

- code, tests, documentation or configuration;
- a commit message or a branch name;
- a pull request title or description, a review comment, or an issue.

Push, open pull requests or post comments only when the human you work with has explicitly asked for it.
